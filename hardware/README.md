# Hardware

Each folder here holds one device's printed parts, exported from Onshape.

- [cube](cube/onshape.toml): the orientation cube. No exports yet.

Every folder has an `onshape.toml` that names the Onshape document, its Part Studios and the version the files were exported from, and a `SHA256SUMS` file once it has exports. How to export and update them is in [docs/export-from-onshape.md](../docs/export-from-onshape.md).
